# Local embedding runtime

The trusted worker/importer supplies exactly `context`, `predicate`, `positives`, and `negatives`. Values are anonymous structural JSON from the admitted worker projection. This encoder is not a grammar validator and must never be wired to raw HTTP JSON or source text.

Provision the isolated environment with the system CPython 3.12:

```sh
/usr/bin/python3 retrieval/bootstrap_ml.py --provision-runtime .tools/retrieval/models
PYTHONPATH=retrieval .tools/retrieval-venv/bin/python -m unittest discover -s retrieval/tests -p test_ml.py -v
```

The 62-wheel lock covers inference, the official CPU-only torch 2.14.1 wheel, PostgreSQL and LangGraph dependencies. The bootstrap creates a plain CPython 3.12 environment, seeds a hash-checked pip wheel if Ubuntu lacks ensurepip, and recreates only the owned runtime when its Python version or isolation setting is wrong. Training checks the pinned torch version and a portable hash of the wheel's payload RECORD rows. Generated bytecode, local installer metadata and entry-point wrappers are excluded from that portable digest. System and Anaconda site packages are excluded.

The final exact dependency audit found no published advisory matches; this is a snapshot, not a whole-application security guarantee. `dependency-security.json` binds the audit and wheel-lock hashes. Prior vulnerable dependency inventories are preserved as before evidence.

`Encoder().encode_blocks(record)` returns four normalized 768-dimensional blocks; `encode_record(record)` returns the ordered unit-normalized float32 vector of length 3072. All token and chunk budgets are checked before any inference. Pool order is canonicalized and each member receives equal aggregate weight. `Encoder(adapter_path=...)` loads a fitted log-scale matrix; its `model_id` binds pretrained file hashes, recipe and adapter bytes.

`training.train(pairs, output_dir)` fits the actual 3072 diagonal parameters with the frozen 20-epoch CPU recipe. Pairs require train split, record ID, family, certificate ID and distinct left/right cached block matrices. `equivalence_id` masks checked-equivalent targets as distractors. The trusted job must validate certificate IDs and split lineage before calling this low-level optimizer. Synthetic unit tests do not establish corpus quality.

`evaluation.evaluate_cached` measures same-split target ranking, family-macro MRR@10/recall@10/nDCG@10 and family bootstrap intervals. `select_weights` accepts validation queries only. `promotion` enforces the frozen minimum family/source coverage and non-regression rule. Real corpus admission, certificate replay, frozen split manifests and integrity checks remain necessary before promotion.

Model files remain in `.tools/retrieval/models`; corpus feature caches and fitted adapters belong under private `.runtime/corpus`. Runtime embedding makes no network requests. The bootstrap only downloads the exact reviewed public model assets and rejects mismatching file hashes, custom operator domains, external tensor data and unsupported ONNX versions. The observed model uses IR 6 and default-domain opset 11.

`evaluation.run_pilot(rows, private_output_dir)` consumes a repository export with `record_id`, `family`, `split`, `source`, optional `sources`, `status`, `content`, `context_key`, `context_bytes`, and trusted `evidence`. It freezes lineage before fitting, constructs the checked AND/TRUE alternate representation, and stores feature caches privately. It persists all nine validation grid results and chosen weights before computing test metrics, then reports pretrained, trained, predicate-only and combined ranking results with four-block target cosines. Insufficient training/holdout data keeps the quality gate open. This runner does not publish or promote database models.
